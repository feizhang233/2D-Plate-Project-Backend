两个代表性问题分别覆盖：

- 薄板 K/DKQ：四边简支方板，在正弦横向荷载下与解析解比较；
- 中厚板 M/MITC4：四边固支方板，在均布荷载下检查挠度、内力和应力恢复。

阅读时不要背诵最终数字，重点回答三个问题：为什么选这种理论、单元结果怎样进入整体方程、结果通过什么证据验证。
